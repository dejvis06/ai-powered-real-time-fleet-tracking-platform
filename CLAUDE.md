# CLAUDE.md

## Development Workflow

Before implementing anything, read the project documentation [AI-Powered Real-Time Fleet Tracking Platform.docx](AI-Powered%20Real-Time%20Fleet%20Tracking%20Platform.docx) located in the repository root, in the following order. 

### 1. System Design

Read the **System Design** section first to understand the complete architecture, data flow, service responsibilities, communication patterns, scalability approach, and overall design decisions.

Do not begin implementation until this section is fully understood.

### 2. Claude Implementation Specification

After understanding the architecture, read the **Claude Implementation Specification** section.

This section defines the implementation requirements, project structure, technology stack, coding guidelines, DDD architecture, module layout, and development conventions that must be followed throughout the project.

## Implementation Rules

- Treat the documentation as the source of truth.
- Follow the architecture exactly
- Keep implementations consistent with the documented design.
- Implement incrementally, completing one module or feature at a time before moving to the next.
- When generating code, ensure it aligns with both the System Design and the Claude Implementation Specification.
